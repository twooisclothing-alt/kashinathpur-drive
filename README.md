# কাশিনাথপুর ড্রাইভ

পাবনার কাশিনাথপুর মোড় আর আশেপাশের প্রায় ৭ কিমি এলাকার আসল ম্যাপে লাল স্পোর্টস কার চালানোর ৩D গেম। মোবাইল বা কম্পিউটারের ব্রাউজারে সরাসরি খেলা যায়।
